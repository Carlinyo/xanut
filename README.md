# Միս ու մթերք — сайт (Vue 3 + TypeScript + Vite) · https://www.misumterq.com

Магазин мяса и шашлыка в Джермуке: каталог, заказ шашлыка и мяса с доставкой, регистрация с кодом подтверждения.

## Запуск

Сначала запустите сервер (папка `merkhanut-api`: `npm install`, `npm run setup`, `npm run dev` — см. его README). Затем здесь, во втором окне:

```bash
npm install
npm run dev        # http://localhost:5173
```
Запросы `/api` Vite передаёт серверу на `http://127.0.0.1:3000` (`vite.config.ts`).
Чтобы вести разработку без локального сервера, на задеплоенном API, создайте `.env.local` со строкой
`API_PROXY_TARGET=https://xanutback.vercel.app`.

## Деплой

API задеплоен на `https://xanutback.vercel.app`. Сайт обращается к нему **через свой же домен** (`/api/...`):
на Vercel это делает `vercel.json` (rewrites), там же — отдача `index.html` для всех адресов вроде `/products/5`.
Кроме `/assets/`: несуществующий файл сборки — ошибка 404, а не страница сайта.
Файлы `/assets` браузер **сверяет с сервером при каждой загрузке** (`Cache-Control: max-age=0, must-revalidate`; если файл
не менялся, сервер отвечает коротким «не изменился», файл заново не качается). Не ставьте им «immutable» на год: браузер,
открывший сайт в момент выкладки, может получить вместо файла ошибку и хранить её год — сайт у него остаётся без оформления
или не открывается вовсе (так уже было). Страховка для стилей — в `src/main.ts`: пока стили не пришли, страница скрыта,
а не пришли — файл стилей загружается ещё раз мимо кэша.
Не задавайте `VITE_API_URL` с адресом API напрямую: cookie сессии у сервера `SameSite=Lax`, а разные поддомены
`*.vercel.app` браузер считает разными сайтами — вход перестанет сохраняться.

Vercel: импортируйте репозиторий, пресет Vite (`npm run build` → `dist`) определится сам. Другой хостинг —
`npm run build`, папку `dist` отдавать со своего домена, `/api/*` проксировать на `https://xanutback.vercel.app/api/*`.

## Где что менять

Все тексты сайта — в `src/locales/hy.json`:
- `contact.phone`, `contact.email`, `contact.address`, `contact.hours` — контакты магазина (они же подставляются в политику конфиденциальности вместо `{phone}`, `{email}`, `{address}`);
- `privacy.sections[0]` — владелец данных (ИП и ИНН/ՀՎՀՀ); `privacy.updated` — дата редакции политики.

Координаты магазина для карты — `src/shop.ts`.

Ограничения, которые сайт повторяет за сервером, — меняйте вместе с `merkhanut-api`:
- шашлык и мясо на вес (0.5–50 кг шагом 0,5 кг, цена = цена за кг × вес; комментарий к шашлыку до 300 знаков) — `src/utils/kebab.ts`;
- какое время предлагать: в корзине только мясо — любое с 10:00 до 22:00 с шагом 30 минут (список приходит с сервера, `times` в `/api/slots`), есть хоровац — часовые окна; решает `exactTime` в `src/stores/cart.ts` так же, как сервер;
- не больше 99 штук одной позиции в корзине — `MAX_QTY` в `src/stores/cart.ts` (бонусного товара — не больше 10, это число приходит с сервера);
- требования к паролю — `src/utils/passwordPolicy.ts`.

## Картинки

Изображения товаров и фоны генерируются скриптами (нужны `playwright` и `sharp`, в зависимости проекта они не входят):

```bash
npm i -D playwright sharp && npx playwright install chromium
node tools/render-art.mjs            # public/img/art/*.webp
node tools/render-backgrounds.mjs    # public/img/bg/*.webp
node tools/render-sketches.mjs       # public/img/cat/*.webp — карандашные рисунки плиток «Տեսականի» (только sharp)
```

Фотографии товаров кладутся в `public/img/art` (какое фото у какого рисунка — `src/utils/art.ts`). После добавления новых запустите `node tools/shrink-photos.mjs` (нужен только `sharp`): он уменьшит крупные до 1000 px по длинной стороне — фото с телефона весит 2–3 МБ, после — около 200 КБ — и сделает маленькие копии до 400 px в `public/img/art/sm/` (в среднем 20 КБ вместо 100 КБ). Карточки, корзина и окна показывают копию, страница товара — полное фото (`ProductArt.vue`, `full`); копии нет — показывается полное фото, так что забытый запуск ничего не ломает, только грузит больше.

Картинки `/img/*` браузер держит в кэше сутки (`vercel.json`), потом ещё неделю показывает из кэша и тем временем обновляет: заменили фото под тем же именем — посетители увидят новое не позже чем через день. Если нужно сразу — положите фото под новым именем.

Фото напитков лежат в подпапках `public/img/art/wines`, `Vodka`, `cognac` (уже в `.webp`, до 1000 px; исходные PNG по 1–2 МБ перенесены в `photo-originals/` — эта папка в git не попадает и на сайт не выкладывается, её можно удалить). `shrink-photos.mjs` обрабатывает только саму `public/img/art`, без подпапок: новые фото в подпапках уменьшайте так же — до 1000 px и в `.webp`.

Плитки «Տեսականի» на главной у напитков — бутылки (`wine`, `vodka`, `cognac`): сцены в `tools/render-sketches.mjs`, как и у остальных разделов. Тёмные баннеры под «Հատուկ առաջարկներ» (`promos` в `hy.json`, `PromoGrid.vue`) показывают в белом круге тот же карандашный рисунок, что плитка их раздела (`cat`): поменяли рисунок раздела в админке — меняется и баннер.

## Бонусы

Страница «🎁 Բոնուսներ» (`/bonus`): баланс баллов, правила, группы клиентов, обмен на бонусные товары и история. С каждого заказа начисляется процент от стоимости товаров (новому клиенту — 2%); баллы доступны после доставки. Бонусный товар кладётся в корзину за баллы и приезжает вместе с заказом. Баланс и правила проверяет сервер (README сервера → «Бонусная программа»).

## Группы клиентов

Новый, постоянный (по умолчанию — 10 заказов за месяц, каждый от 3000 ֏) и VIP (25 заказов за месяц, каждый от 10 000 ֏) — у каждой группы своя акция: скидка на товары, процент баллов, бесплатная доставка. Группа, заработанная в месяце, действует до конца следующего месяца и продлевается ещё на месяц, если условия выполнены снова (срок приходит с сервера — `level.month.until`). Корзина и окно подтверждения показывают цену с акцией (`src/utils/segments.ts` считает так же, как сервер; окончательную цену считает сервер). Покупатель видит свою группу, до какого дня она действует и цель месяца (подняться выше или сохранить группу на следующий месяц) в кабинете и на странице бонусов. Акции и пороги меняются в админке.

## Комбо

Комбо — товар с признаком «Կոմբո» (переключатель в форме товара в админке): набор по одной цене. Комбо показываются первыми в «Հատուկ առաջարկներ» (страница `/offers` и блок на главной — вместе с товарами со скидкой), на карточке — метка «Կոմբո · առաքումն անվճար». Если в корзине есть комбо, доставка бесплатна (`cart.hasCombo`; так же решает сервер). Хоровац-комбо «за кг» заказывают через окно шашлыка — там же видно, что входит в комбо.

## Админка

`/admin` (только для роли admin):
- **Պատվերներ** — заказы; новый заказ появляется сам, со звонком и подсветкой: открытая страница раз в 15 с (в фоновой вкладке — раз в минуту) спрашивает номер последнего заказа (`src/utils/ticker.ts` — таймер в Web Worker, его браузер не замедляет в фоне). Звук — Web Audio, без файла (`src/utils/sound.ts`); браузер разрешает его после первого нажатия на странице, кнопка 🔔 выключает звук. В фоновой вкладке число новых заказов видно в заголовке.
- **Հաճախորդներ** — все пользователи: контакты, заказы, сумма покупок, баллы, группа; фильтр по группе, поиск, сортировка; группу можно назначить вручную; «🏷 Ակցիաներ» — акции и пороги групп.
- **Բողոք/առաջարկ** — жалобы и предложения с сайта (вкладка «Կարծիքներ» — отзывы о заказах): текст, контакты для ответа, заказ; отметка «Լուծված է» (разобрано). Метка на вкладке — сколько ещё не разобрано.
- **Բոնուսային ապրանքներ** — товары за баллы.
- У пользователя в «Հաճախորդներ» — «Դարձնել աշխատակից»: работник видит только раздел заказов.

## Работники

`/staff` — «🧑‍🍳 Պատվերներ» (только роль worker; администратора отправляет в `/admin`, сервер отвечает ему 403): заказы в работе и недавно готовые, у каждого одна кнопка следующего шага (`src/views/StaffView.vue`, карточка — `AdminOrderCard` в режиме `staff`): у онлайн-заказа «Ընդունել» → «ждём оплату» → «Սկսել պատրաստել» → «Պատրաստ է», у остальных — сразу «Պատրաստ է». Новые заказы и пришедшие оплаты появляются сами, со звонком (пока есть заказы, ждущие оплату, страница спрашивает весь список).
**Работнику открыт только этот раздел:** любой другой адрес сайта ведёт его в `/staff` (`router.ts`; поэтому каждый первый переход ждёт `/auth/me`).
Страница открывается без сайта вокруг (`meta.bare` в `router.ts` → `templates/BareLayout.vue`, выбор оболочки — `App.vue`): ни шапки, ни подвала, ни корзины, каталог не грузится — только вход (`/auth/me`) и заказы. Выход — кнопкой «Ելք» на самой странице. Нажатый шаг сразу виден на экране, не дожидаясь сервера (он может отправлять покупателю письмо); если сервер ответил ошибкой — заказ возвращается в прежний статус с причиной.

## Оплата

- **Доставка:** наличными курьеру или картой онлайн (AmeriaBank) — «картой курьеру» нет. **Самовывоз:** наличными, картой в магазине или онлайн. Онлайн-оплата видна, только когда сервер получил данные банка (`/api/config` → `onlinePay`); иначе при доставке — только наличные, как раньше.
- Онлайн, по шагам: **покупатель заказал → работник принял → покупатель оплатил → работник начал готовить**. После заказа в банк покупатель не уходит: корзина пишет «ждём подтверждения магазина». Когда заказ приняли, приходит письмо, а в «Իմ հաշիվը» у заказа появляется «Վճարել առցանց» (страница сама обновляет заказы раз в 20 с, пока есть неоплаченный онлайн-заказ). Кнопка ведёт на страницу оплаты банка (`src/utils/payment.ts`; переход разрешён только на `*.ameriabank.am`), банк возвращает на `/payment/return` (`src/views/PaymentReturnView.vue`) — страница спрашивает итог у сервера, а тот — у банка. Не прошла — «Վճարել կրկին».
- Как это устроено, покупателю рассказывает раздел «Առցանց վճարում» на странице «Մեր մասին» (`about.payment` в `hy.json`).
- **Доставка дальше 5 км** — 2000 ֏ (без порога бесплатной доставки): корзина считает расстояние по точке на карте или по проверенному адресу (`cart.deliveryKm`), так же, как сервер.

## Коды подтверждения

Код подтверждения (регистрация, вход с нового устройства, восстановление пароля) приходит **только на почту** — SMS сайт не отправляет, телефон покупателя нужен лишь для связи и доставки. Шаг ввода кода — `OtpStep.vue` (вход и регистрация) и `ResetForm.vue` (новый пароль).

## Жалобы и предложения

Окно «💬 Բողոքներ և առաջարկներ» (`FeedbackDialog.vue`) открывается из подвала любой страницы, со страницы «Կապ» и кнопкой «Հայտնել խնդրի մասին» у каждого заказа в кабинете (тогда это сразу жалоба на этот заказ). Писать можно и без входа: гость по желанию оставляет почту или телефон для ответа, вошедшему ответят на контакты из аккаунта. Магазину приходит сообщение в Telegram, запись появляется в админке.

## Безопасность сайта

`vercel.json` отдаёт заголовки безопасности: Content-Security-Policy (скрипты только с этого сайта, шрифты — Google Fonts,
карта — OpenStreetMap), запрет показа сайта внутри чужих страниц (защита от «кликджекинга»), `nosniff`, HSTS и другие.
**Если подключаете внешний сервис** (аналитику, виджет чата, другую карту) — добавьте его домен в нужную директиву
CSP (`script-src`, `connect-src`, `frame-src`, `img-src`), иначе браузер его заблокирует (ошибка видна в консоли).
Формы «Կապ», жалоб и подписки содержат скрытое поле-ловушку для ботов (`HoneypotField.vue`).

## Вход и заказы

- **Забыли пароль** — ссылка «Մոռացե՞լ եք գաղտնաբառը» на странице входа → `/forgot`: почта → код → новый пароль, сразу вход.
  На других устройствах сессии закрываются. После 20 неверных паролей за час вход в аккаунт временно закрыт — сайт
  предлагает восстановить пароль.
- **Կրկնել պատվերը** — у каждого заказа в кабинете: позиции кладутся в корзину по сегодняшним ценам; чего уже нет в продаже,
  сайт называет. Шашлык повторяется для заказов, сделанных после этого обновления (в старых не сохранялся выбор мяса и веса).
- У покупателя одновременно не больше 3 незавершённых заказов — на четвёртый сайт объяснит, что делать, и даст телефон.

## Поисковики и ссылки

`index.html` — описание и картинка для превью ссылок в Facebook, Telegram, Viber (`public/og.jpg`) и данные магазина для
Google (адрес, телефон, часы — блок `application/ld+json`). `public/manifest.webmanifest` и `public/icons/` — иконка при
добавлении сайта на главный экран телефона. `public/robots.txt` и `public/sitemap.xml` — для поисковиков.
Иконка во вкладке и в выдаче Google — `public/favicon.ico` (16, 32 и 48 px, сделана из `public/icons/icon-192.png`) и `public/favicon.svg`.
Без настоящего `favicon.ico` по этому адресу отдавалась страница сайта, и Google показывал вместо иконки глобус.
Адрес сайта — `https://www.misumterq.com`: так он открывается на Vercel (адрес без `www` перенаправляет сюда), так его знает Google.
Прописан в `index.html`, `robots.txt` и `sitemap.xml` — при смене домена замените его там же.
Неизвестный адрес показывает страницу «Էջը չի գտնվել».

## Тестовый режим

Пока на сервере не вставлен пароль приложения Gmail, письма не уходят: при регистрации и входе код подтверждения показывается прямо на экране ввода кода — плашка «🧪 Թեստային ռեժիմ»; нажмите на код, и он подставится сам. После `npm run setup` на сервере плашка исчезает, коды приходят на почту.
